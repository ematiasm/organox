Design system — admin-app

Tokens captured from frontend/src/app.css and components in frontend/src/lib/components/ui/. Everything below exists in the project today.

Stack: Tailwind v4 + shadcn-svelte (vega preset, olive base). Raw values are oklch(); here they are converted to sRGB for readability.

Color

The 33 tokens in :root; the dark theme redefines 32. The Tailwind utility is the name prefixed with --color- (bg-card, text-muted-foreground…).

⚠️ Two sync findings, not corrected in app.css: --warn in light mode (2.96:1) is insufficient for normal text — use it for a dot, border or fill; and --muted-foreground in light mode (4.25:1) is just below AA, as supplied by the vega preset. One darker step fixes it without changing the color family.

Notes

No standalone hex colors on screens: always use a token utility. Decimals are displayed as strings exactly as received from the API. The only custom project token is --warn, because the vega preset has no warning color and --chart-* is grayscale.
